# Hallucination Detection via Inter-Agent Disagreement

Do independently-queried large language models **disagree more on questions they get
wrong**? This repository is the full experimental codebase for that question: a
multi-model "panel" is asked each question in isolation (no debate, no shared
context, temperature 0), the spread of their answers is quantified with three
families of disagreement measure, and that spread is tested as a zero-resource
hallucination signal against graded correctness.

* **Datasets:** SimpleQA Verified, TruthfulQA (open-ended + multiple-choice), RAGTruth.
* **Model pool:** a frozen 3 × 3 grid — Meta / OpenAI / Qwen families, each at a
  small / large / strong capability tier — served through OpenRouter. Panels
  (within-family, cross-family, tier-matched, leave-one-out, …) are formed
  *post-hoc* over the cached pool, so adding a panel costs nothing.
* **Disagreement measures:** answer-level (token Jaccard, MC letter match),
  semantic-level (entropy of NLI meaning-clusters — Semantic Entropy), and
  claim-level (decompose-and-verify, for RAGTruth).
* **Reproducibility:** every model response is content-addressed and **committed to
  the repo**, and every reported table is regenerated by a script from a
  **committed results file**. The headline numbers reproduce with no API keys, no
  GPU, and no network.

> Status: research code for an MSc individual project (Imperial College London).
> It is organised for reproducibility of the accompanying report, not as a
> packaged library. Section/table numbers below (e.g. "report §4.6") refer to that
> written report, which is not part of this repository.

## TL;DR — reproduce the headline numbers offline

```bash
git clone https://github.com/hanasel/hallu-agents.git
cd hallu-agents

python3.12 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install pytest                   # only needed for the test suite

# 1. Unit tests — 65 tests, ~1 s, no network, no keys
python -m pytest -q

# 2. Regenerate the main SimpleQA analysis from the committed results file
#    (--analyse-only = re-report from disk; zero API calls)
python scripts/disagreement_pilot.py --dataset simpleqa --n 1000 \
    --analyse-only --out outputs/simpleqa_3x3_results_1000.jsonl

# 3. The offline panel-subset sweep (report Appendix B) — pure stdlib, no torch
python scripts/panel_sweep.py --file outputs/simpleqa_3x3_results_1000.jsonl \
    --format open --grader judge --judge-only --out outputs/panel_sweep9_simpleqa
```

**No `.env`, no API keys, no GPU are required for any of the above.** The agent
response cache (`cache/agent_responses/*.jsonl`), the raw datasets
(`data/*_data/`), and the per-question results files (`outputs/*.jsonl`) are all
committed. API keys are needed **only to re-query models from scratch** (see
[API keys](#api-keys-env)).

The repository is ~305 MB checked out, most of it the committed cache and the
RAGTruth corpus.

## How it works

Four design decisions make the experiments cheap to re-run and hard to fudge.

### 1. Pool, not panel

`scripts/disagreement_pilot.py` queries a **pool** of models — each model answers
every question exactly once. A "panel" is a *subset* chosen during analysis. The
cache is keyed on `(model, prompt, temperature, max_tokens, …)`, **not** on panel
membership, so once the pool is queried every panel — within-family pairs,
cross-family triples, tier-matched triples, leave-one-out, the full 9 — is free to
evaluate. `scripts/panel_sweep.py` exploits this to score all `2⁹ − 10 = 502`
non-trivial subsets with no further API calls.

### 2. Deterministic agents + a content-addressed cache

Every agent is queried at **temperature 0**. Any disagreement observed is then
attributable to *differing model knowledge*, not to sampling noise (contrast
SelfCheckGPT, which samples one model hot — that baseline is implemented
separately in `scripts/harvest_selfcheck.py`). Each response is hashed on
everything that affects it and written to `cache/agent_responses/<provider>__<model>.jsonl`
as append-only JSONL. Re-running replays exact bytes; errored responses are never
cached, so a rerun retries them.

### 3. One grader, one set of panel definitions

`evaluation.grade_correct` and `agents.panels` are the single source of truth for
correctness grading and panel composition across *every* dataset and script. An
earlier version of this project had two independently-maintained graders that
silently diverged; `evaluation/grading.py`'s docstring records what went wrong.

### 4. Manifests and committed artifacts

Harvest/pilot runs write a `<out>.manifest.json` next to their results:
resolved model list, prompt format, query settings, per-model reasoning
parameters, NLI model, dataset source/n/seed, git commit SHA, and UTC
start/end. `--analyse-only` re-derives every reported number from the committed
results file; `--resume` continues an interrupted run only if the manifest
matches.

## The pipeline, end to end

```
                 data/                      agents/ + cache/            disagreement/           evaluation/            scripts/*  report
   ┌───────────────────────┐   ┌───────────────────────────┐   ┌──────────────────┐   ┌───────────────┐   ┌───────────────────┐
   │ load_simpleqa()       │   │ pool() → 9 GroqAgents on   │   │ JaccardDisagree- │   │ grade_correct │   │ AUROC / AUC-PR /  │
   │ load_truthfulqa()     │──▶│ OpenRouter, T=0           │──▶│ ment             │──▶│  (NLI proxy   │──▶│ lift, per panel,  │
   │ load_ragtruth()       │   │ query_agents() per Q      │   │ SemanticEntropy- │   │  or LLM judge)│   │ per family/tier,  │
   │  → Sample protocol    │   │ every response cached      │   │ Disagreement     │   │               │   │ held-out, calib.  │
   └───────────────────────┘   └───────────────────────────┘   │ MCExactMatch     │   └───────────────┘   └───────────────────┘
                                                               └──────────────────┘
```

1. **Query** — `disagreement_pilot.py` builds `agents.panels.pool()` (9 agents),
   sends each question once per agent, caches every `AgentResponse`. Empty +
   `finish_reason="length"` is a truncation and aborts past `--max-bad-questions`;
   an explicit abstention (prose regex, or no extractable MC letter) is recorded
   as a third state, excluded from clustering, and graded `NOT_ATTEMPTED`.
2. **Score** — each panel's responses go through the disagreement measures. Open
   mode: Jaccard (continuous) + Semantic Entropy (normalised NLI-cluster
   entropy). MC mode: `MCExactMatch` (letter-mismatch fraction) — NLI never runs.
3. **Grade** — `grade_correct` labels each response correct / incorrect /
   unclear. MC: deterministic letter comparison. Open: directional-NLI proxy
   against the sample's `correct_answers` / `incorrect_answers`,
   question-conditioned. `--judge-model` adds an independent LLM regrade and the
   report prints both side by side.
4. **Analyse / report** — rank statistics (AUROC, AUC-PR, lift) against graded
   incorrectness, broken down by panel size, family composition, capability
   tier, and leave-one-out; plus a fixed per-question row written to `--out` for
   downstream offline analysis (`panel_sweep.py`, `calibration.py`,
   `nli_sensitivity.py`).

Each `--out` results row stores every agent's raw response text, per-agent
grades (NLI and judge), per-agent abstention/truncation flags, and cluster
assignments — enough to re-score any subset offline forever.

### Re-querying from scratch (costs API credits)

Drop `--analyse-only` and provide the relevant key. Because the response cache is
committed, only genuinely new `(model, prompt, …)` tuples hit the network:

```bash
export OPENROUTER_API_KEY=...
python scripts/disagreement_pilot.py --dataset simpleqa --n 1000 \
    --judge-model <out-of-pool-model-id> \
    --out outputs/simpleqa_3x3_results_1000.jsonl --resume
```

`--resume` appends and skips completed questions, but only if the pool, question
set, and seed match the existing file's manifest — otherwise it aborts rather
than mixing incomparable rows.

## Running the tests

```bash
pip install pytest
python -m pytest -q
```

65 tests, ~1 second, **fully offline** — the OpenAI client and the NLI backend are
replaced with deterministic fakes. Coverage:

* `tests/test_groq_agent.py` — retry/backoff, permanent vs transient error kinds,
  reasoning-param resolution and its effect on the cache key, `to_dict` round-trip.
* `tests/test_panels.py` — every Qwen model has a reasoning-suppression entry
  (a missing one silently leaks chain-of-thought into every measure); the two
  Qwen ladders are well-formed; the already-cached Qwen 3.6 params are frozen
  (they are part of the cache key for the committed 1000-question run).
* `tests/test_disagreement_pilot.py` — panel construction, scoring, abstention
  handling, label logic.

The `scripts/test_*.py` files are ad-hoc manual smoke checks, **not** pytest
tests, and are excluded from collection.

## Reproducibility & determinism notes

* **Temperature 0** on every panel agent — disagreement reflects model knowledge,
  not sampling. The hot-sampling baseline is isolated in `harvest_selfcheck.py`
  and `pilot_sampled.py`, which seed each draw.
* **Cache key** = SHA-256 of `{model, prompt, round(temperature, 6), max_tokens,
  extra}` where `extra` folds in the system prompt, any `seed`, and the resolved
  reasoning parameters. Two agents differing only in reasoning effort never share
  a cache entry. Errored and length-truncated responses are not cached.
* **Seeds.** Dataset subsetting is seeded: loaders default to `seed=42`;
  `disagreement_pilot.py` defaults to `--seed 0`. Choice-order shuffling in
  TruthfulQA is deterministic per question index.
* **Manifests.** `<out>.manifest.json` records the git SHA
  (`e5c03e6` at the time of writing), model list, query settings, per-model
  reasoning params, NLI model, and UTC timestamps for every harvest/pilot.
  `scripts/appendix_provenance.py` recovers the served-on date range from cache
  record timestamps.
* **Grader independence caveat** (stated in `disagreement_pilot.py`): by default
  the *same* `CrossEncoderNLI` instance clusters answers and grades them, which
  correlates their errors in the direction that flatters "disagreement predicts
  wrongness". `--judge-model` regrades with an independent LLM; the report prints
  AUROC under both, and any result that only survives the NLI grader should be
  read as an artifact. `panel_sweep.py --judge-only` builds the label from the
  judge alone (no NLI fallback) — this is the label behind the report's figures.
* **Determinism boundary.** LLM providers are not bit-reproducible across time
  even at temperature 0; this is why the cache is committed rather than
  regenerated. Re-querying may produce slightly different text and therefore
  different downstream numbers.

## Configuration reference

### `scripts/disagreement_pilot.py` (main driver)

| Flag | Default | Meaning |
|---|---|---|
| `--dataset` | `simpleqa` | `simpleqa` or `truthfulqa` |
| `--prompt-format` | `open` | `open` (free text) or `mc` (TruthfulQA only) |
| `--n` / `--seed` | `200` / `0` | question count / subset seed |
| `--models` | — | comma-separated extra model ids to add to the pool |
| `--qwen-ladders` | off | add the 6 Qwen size/generation ladder models |
| `--nli-model` | `cross-encoder/nli-deberta-v3-base` | NLI checkpoint for clustering + grading |
| `--judge-model` / `--judge-provider` | — / `openrouter` | independent LLM regrade (use an out-of-pool model) |
| `--strict` | off | cluster only on mutual entailment |
| `--single-linkage` | off | compare only to a cluster's first member |
| `--short-answer-keys` / `--short-entity-keys` | off | short-circuit NLI with extracted date/number/formula keys; writes a distinct `--out` |
| `--no-concise` | off | do not force short answers (reproduces the saturated baseline) |
| `--max-bad-questions` | `5` | abort after this many errored/truncated responses |
| `--analyse-only` | off | re-report from `--out`; no queries |
| `--resume` | off | append to `--out`, skipping completed questions (manifest must match) |
| `--out` | per-dataset default | results JSONL path |

### `scripts/panel_sweep.py` (offline subset sweep)

| Flag | Meaning |
|---|---|
| `--file` | a `disagreement_pilot.py` results JSONL |
| `--format` | `mc` (MCExactMatch) or `open` (restricted full-pool clustering) |
| `--grader` | `nli` or `judge` (judge falls back to NLI unless `--judge-only`) |
| `--judge-only` | build the label from judge grades alone — the report's figures |
| `--out` | output path stem (writes `<out>.csv` and `<out>.heldout.csv`) |

`harvest.py` / `harvest_selfcheck.py` take `--models`/`--model`, `--prompt-format`,
`--n`, `--seed`, `--source`, `--out` (and `--k` / `--temperature` for
self-check). `rgt_verify_pilot.py` takes `--task {qa,summarization,data2txt}`,
`--n`, `--max-claims`, `--diagnose-full`, `--out`, and resumes by default
(`--fresh` truncates).

## Known gotchas

* **Run scripts from the repo root** — `python scripts/foo.py`, not
  `cd scripts && python foo.py`. Each script does
  `sys.path.insert(0, <repo root>)`; `scripts` is an implicit namespace package
  (no `__init__.py` on purpose).
* **The repo intentionally commits large artifacts.** Only `.env` is git-ignored.
  The thorough `gitignore` file in the root is a *template that was never
  activated* (it is not named `.gitignore`). As a result `cache/`, `outputs/`,
  and `data/*_data/` are tracked — which is what makes offline reproduction
  possible — but the checkout is ~305 MB. If you want the standard ignore rules,
  `cp gitignore .gitignore` (and be aware you then lose the committed cache from
  future clones).
* **`requirements.txt` is close but not exact:** `scipy` and `pytest` are not
  listed (scipy arrives via scikit-learn; add pytest for tests), `pandas` is
  listed but effectively unused, and `datasets` is only for the legacy TruthfulQA
  snapshot.
* **Model ids track a live OpenRouter catalog.** `agents/panels.py` pins specific
  slugs (e.g. the strong tier); `providers.py` notes a `TODO` to confirm one
  against the live catalog. A renamed or retired model will (a) fail
  `assert_models_available` at pool-construction time and (b) miss the committed
  cache, forcing a re-query. Reproduction via `--analyse-only` is unaffected.
* **First open-ended run is slow:** it downloads the NLI checkpoint and loads
  torch. MC mode and `panel_sweep.py` skip both.
* **RAGTruth claim-level verification is quota-bound.** `rgt_verify_pilot.py`
  stops cleanly on an API error with the cache intact; `scripts/run_*.sh` loop it
  across quota windows. It needs `TOGETHER_API_KEY`.
* **`--analyse-only` rewrites `--out`.** The content is identical; `git status`
  will still show the file as modified until you `git checkout` it.
